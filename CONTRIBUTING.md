# Contributing to NUMUW

NUMUW is a public repository for a commercial Growth Systems Studio site.

## Before changing anything
Read docs/SYSTEM-OF-RECORD.md, docs/ARCHITECTURE.md, docs/QA.md and docs/CONTENT-POLICY.md.
Inspect the affected page and the routes it links to.

## Required
- reuse existing design and route conventions
- avoid new dependencies without a documented reason
- keep marketing claims factual
- preserve privacy, security and ownership boundaries
- run the release audit
- review adjacent routes for regressions

## Release discipline
Source-level success is not the same as live production success.
Live checks must be marked complete only after direct verification.
