# NUMUW | نُمو

Static landing page (Arabic RTL + English toggle). No build step, no backend, no dependencies.

## Run locally
`npx serve .` then open http://localhost:3000

## Deploy (GitHub Pages)
Settings -> Pages -> Deploy from branch -> `main` / root. Site URL assumed: `https://ahmedsaturki.github.io/numuw-studio/` (update canonical / og tags in `index.html`, `robots.txt`, `sitemap.xml` if different).

## Files
`index.html` · `style.css` · `script.js` · `favicon.svg` · `og-image.png` · `404.html`
