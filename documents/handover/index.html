NUMUW - Handover Checklist

قائمة تسليم وملكية تمنع بقاء الأصول أو الصلاحيات معلقة بعد انتهاء المشروع.

Core contents

  • Domains and hosting ownership verified
  • Website / source files delivered
  • Brand files and editable masters delivered
  • Analytics / measurement access transferred
  • Automation workflows and documentation delivered
  • Credential transfer through secure method; no secrets stored in project files
  • Temporary access removed or rotated after handover
  • Backup / export retained where agreed
  • Training and operating notes
  • Support window and escalation route
  • Acceptance / sign-off recorded
الملكية الفعلية والاستثناءات تعتمد على النطاق والعقد والدفع، وليس على هذه القائمة وحدها.
