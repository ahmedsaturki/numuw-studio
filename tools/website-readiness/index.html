    READINESS MODEL

    ما الذي تقيسه الأداة وما الذي لا تقيسه؟

    تقيس وجود أساسيات مهمة من وجهة نظرك. لا تزحف إلى موقعك، ولا تفحص Core Web Vitals أو Search Console أو Google Business Profile تلقائيًا.

    Message

    هل يفهم الزائر من أنت وماذا تقدم؟

    Conversion

    هل توجد خطوة تالية واضحة وقابلة للتنفيذ؟

    Trust

    هل المعلومات والأدلة والهوية موثوقة؟

    Technical

    الـself-audit ليس بديلًا عن فحص فعلي عند الحاجة.

    Purpose

    تقييم ذاتي لأساسيات رسالة الموقع والثقة والتحويل والجاهزية التقنية.

    Inputs & assumptions

    أنت تختار وجود عناصر محددة؛ الأداة لا تثبت أن الموقع الفعلي ينفذها بشكل صحيح.

    Limits & privacy

    لا crawling ولا Core Web Vitals ولا Search Console ولا Google Business Profile، والمدخلات محلية في المتصفح.

    Next action

    استخدم أقل نتيجة كأولوية، ثم انتقل إلى Diagnostic أو Website scope مناسب بدل إصلاح كل شيء مرة واحدة.
