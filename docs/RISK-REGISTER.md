# NUMUW Risk Register

| Risk | Impact | Detection | Mitigation |
|---|---|---|---|
| Route sprawl / duplicate intent | SEO + UX fragmentation | registry + sitemap audit | canonical IA |
| Generic industry pages | weak differentiation | content review | sector-specific buying logic |
| Service grab-bag offers | poor conversion | offer matrix | diagnostic-first ladder |
| Unverifiable proof | trust/legal risk | content policy | evidence hierarchy |
| Tool results interpreted as facts | decision risk | tool contract audit | scenario/limits language |
| Third-party dependency creep | privacy/performance risk | source audit | explicit exception review |
| Credential leakage | security risk | document review | client-owned accounts + secure transfer |
| Live site differs from source | release risk | deployment + browser gate | explicit live verification |
| Branch divergence | governance risk | branch inventory | one active system branch, close superseded work |
| Benchmark gaming | false completion confidence | audit separation | benchmark never equals product quality |
