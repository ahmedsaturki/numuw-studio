# NUMUW QA Protocol

## Static checks
- All internal links resolve to an existing path.
- No page contains fake testimonials or unverifiable metrics.
- No hard-coded secret or API key.
- No unnecessary dependency or framework is introduced.

## Browser checks
- Home loads with meaningful content.
- Landing hub and at least three specialized landings load.
- Tools execute without console errors.
- Mobile menu opens and closes.
- WhatsApp links contain a valid phone target.
- Print/save-PDF buttons work on business documents.

## Release checks
- GitHub Pages URL confirmed.
- HTTPS confirmed.
- Canonical and sitemap updated.
- Structured data validated.
- Mobile visual QA completed.
- Lighthouse/Core Web Vitals reviewed.
