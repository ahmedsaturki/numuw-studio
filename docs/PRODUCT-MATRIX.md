# NUMUW Product Matrix

| Product | Best fit | Core deliverable | Starting price |
|---|---|---|---:|
| NUMUW Diagnostic | Unclear or competing priorities | Baseline + prioritized opportunity map + recommendation | Scoped before paid work |
| Digital Kickoff | Focused digital foundation | Offer/presence + site/landing + SEO foundation + handover | 8,000 EGP |
| Automation Sprint | One defined repetitive workflow | Process map + workflow + tests + exceptions + handover | 8,000 EGP |
| Growth System | Multiple connected layers | Connected architecture + staged build + measurement + handover | 24,900 EGP |
| Growth Partner | Existing foundation + ongoing optimization | Monthly priorities + implementation + review loop | 6,500 EGP/month |

## Product rules

Every product page must explain fit, non-fit, scope, client responsibilities, assumptions, acceptance, ownership, handover, support, starting investment and next action.

Public starting prices are reference points, not blanket quotes. The signed proposal / agreement is the commercial source of truth.

Do not add a product merely to repackage an existing service.
