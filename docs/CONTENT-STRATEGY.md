# NUMUW Content Strategy

## Editorial position

NUMUW competes on clarity, systems thinking and evidence. The content moat should be useful even when the reader never becomes a client.

## Core decision topics

1. How to identify the first growth bottleneck.
2. When a website problem is actually an offer / message problem.
3. When automation is worth building.
4. How B2B lead follow-up breaks revenue.
5. What an industrial buyer needs before contacting a supplier.
6. What should be measured before claiming ROI.

## Content format

Prefer:
- decision guides,
- teardown / diagnostic content,
- checklists,
- operating playbooks,
- before/after evidence when real,
- original frameworks with explicit assumptions.

Avoid:
- generic “10 tips” pages,
- duplicated industry pages,
- content produced only to capture keywords,
- AI summaries without original analysis.

## Evidence standard

When citing an external standard, use the primary source where available. For operational claims, distinguish observed evidence, benchmark, scenario and hypothesis.

## Content lifecycle

Idea → research → outline → draft → source review → fact check → editorial QA → publish → measure → update / retire.
