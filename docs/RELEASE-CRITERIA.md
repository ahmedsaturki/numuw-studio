# NUMUW Release Criteria

## P0 — must pass

- Repository source audit
- Whole-system audit
- GitHub Pages deployment
- No broken internal routes
- No malformed metadata / JSON-LD
- No fabricated proof or unsupported commercial claims
- Product contracts complete
- Tool contracts complete
- Canonical navigation present
- Security reporting path documented

## P1 — production verification

- Browser QA on desktop and mobile
- Keyboard traversal
- Error/empty states for all interactive tools
- WhatsApp / phone verification
- Lighthouse + field Core Web Vitals
- Structured-data / Rich Results validation
- Search Console sitemap/indexing review

## P2 — trust and scale

- Formal legal review of policy/contract language
- Repository branch protection / merge policy
- Backup / recovery verification
- Ownership and credential-transfer rehearsal
- Content update / retirement process
- Real proof ledger as cases accumulate

## Rule

P0 is source-release quality.
P1 is deployed-product proof.
P2 is operational maturity.

Do not report P0 as P1/P2.
