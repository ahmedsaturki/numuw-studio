# NUMUW Tool Matrix

| Tool | Primary question | Output | Next step |
|---|---|---|---|
| Growth Diagnostic | أين أكبر فجوة؟ | Self-assessment index + priorities | Free fit conversation or validated Diagnostic |
| Automation Finder | هل العملية تستحق الأتمتة؟ | Time/cost scenario | Validate workflow, then Automation Sprint scope |
| ROI Scenario Calculator | ماذا يحدث تحت افتراضات مالية مختلفة؟ | Scenario model | Validate assumptions before any commercial decision |
| Growth Project Estimator | ما حجم مكونات المشروع؟ | Scope estimate | Written scope |
| 90-Day Roadmap | ماذا نفعل أولًا؟ | Priority sequence | Scope the first cycle |
| Website Readiness | هل أساسيات الموقع جاهزة؟ | Readiness checklist | Website / conversion review |
| Solution Finder | من أين أبدأ؟ | Best-fit starting path | Relevant product / landing |
| Brief Builder | ماذا أرسل في أول رسالة؟ | Structured client brief | Free fit conversation |

All tools are browser-side decision aids. They do not claim to crawl external systems, access private data without authorization, or guarantee business results.

Tool outputs are directional decision support, not a substitute for a scoped engagement, formal audit or financial advice.
