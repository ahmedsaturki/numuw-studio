# Security Policy

## Scope

This policy covers the public source repository and the deployed NUMUW static site.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting / security advisory channel for this repository:

https://github.com/ahmedsaturki/numuw-studio/security/advisories/new

Do not publish sensitive vulnerability details in a public issue before a coordinated fix is available.

## Supported state

The supported target is the current `main` branch and the current GitHub Pages deployment.

## Disclosure

We aim to validate reports, reproduce the issue, ship a fix when appropriate, and coordinate disclosure responsibly.

## Out of scope

Please do not report ordinary content requests, feature requests, SEO suggestions or expected behavior as security vulnerabilities.
