اطلب التشخيصابدأ بالتقييم الذاتي

Buyer job

“مش عايز أشتري الحل الخطأ قبل ما أعرف أكبر اختناق عندي.”

مكالمة الملاءمة الأولية مجانية. أي تشخيص موسع أو تقرير مدفوع يسبقه نطاق وسعر مكتوبان، ثم يبدأ العمل بعد الاعتماد.
OUTPUT

ما الذي تستلمه؟

الهدف هو تقليل عدم اليقين، لا كتابة تقرير طويل بلا قرار.

Current State

خريطة مختصرة للحضور، الطلب، العملية، الأدوات والاختناقات التي ظهرت في النطاق المتفق عليه.

Baseline

المؤشرات والبيانات المتاحة التي يمكن اعتبارها نقطة مقارنة قبل أي تدخل.

Priority Map

ترتيب فرص ومشكلات حسب الأثر، الجهد، الاعتماد والمخاطر بدل “كل شيء مهم”.

Decision Brief

ما نبدأ به الآن، وما نؤجله، وما لا ننصح ببنائه في المرحلة الحالية.

SCOPE

داخل النطاق وخارجه واضح.

النطاق قد يشمل جلسة، مراجعة أصول وبيانات يقدمها العميل، تحليلًا وترتيبًا للأولويات ومخرجات قرار مكتوبة. التنفيذ البرمجي، الحملات الإعلانية، إنتاج المحتوى أو إعادة البناء الشامل ليست افتراضية ضمن التشخيص إلا إذا كُتبت صراحة.

Dependencies

  • وصول إلى البيانات/الأصول المتفق عليها.
  • شخص مسؤول عن القرارات والمعلومات.
  • تحديد الهدف والسياق قبل بدء العمل.
  • البيانات غير المتاحة تُذكر كـUnknown لا تُخترع.
BOUNDARIES

التشخيص له نطاق واضح.

هدفه تقليل عدم اليقين واتخاذ قرار أفضل، وليس فتح مشروع مفتوح النهاية.

داخل النطاق

  • فهم الوضع الحالي ضمن المعلومات المتاحة.
  • تحديد baseline مناسب للمشكلة.
  • ترتيب الأولويات والخيارات.
  • توصية بخطوة تالية أو منتج مناسب.

خارج النطاق افتراضيًا

  • تنفيذ مستمر بعد اعتماد التشخيص.
  • دراسة مالية أو قانونية متخصصة.
  • بيانات خارجية غير متاحة أو غير موثقة.

مناسب عندما

الأولويات متضاربة، المشكلة عامة، أو تكلفة اختيار الحل الخطأ مرتفعة.

لا نبدأ به عندما

النطاق التنفيذي محسوم بالكامل وتحتاج فقط إلى تنفيذ محدد يمكن وصفه وقبوله دون تشخيص إضافي.

Acceptance

يُعتبر التشخيص مستلمًا عندما تُسلّم المخرجات المتفق عليها ويُتاح نطاق المراجعة المكتوب.

Ownership & support

مخرجات التشخيص تسلّم للعميل وفق العقد؛ أي متابعة لاحقة تكون scope مستقلًا أو دعمًا متفقًا عليه.
